# Cadence app template

A minimal, working app starter for the Cadence screen contract:

- `@cadence/app-kit` for the private screen bridge, `presentation()`,
  `openDrawer(surface)` / `closeDrawer()` and the no-presentation fallback;
- an `app-screens/v2` package with a real app surface;
- the `cadence` contract in `package.json`, so `cadence app dev --package`
  owns the local loop;
- the host-owned frame, board drawer, scrim and close affordance — this app
  never reimplements them.

The host protocol is
`ui/src/features/workspace-apps/screen/screenProtocol.ts`; this template
follows it. The receiver is the pinned `app-kit`, not a private `postMessage`
fork.

## Run it from the Cadence checkout

```sh
cd app-toolchain/template
bun scripts/build.mjs
cadence app check app
node scripts/dev-preview.mjs
```

`scripts/dev-preview.mjs` serves the app surface at
`http://127.0.0.1:${CADENCE_APP_PORT:-3186}/`. It is a surface preview, not a
host: the board-wide drawer requires the Cadence board. For the real loop:

```sh
cadence app dev --package .
```

That runs the declared `check`, then the declared `dev` command; the host sets
`CADENCE_APP_ROOT`, `CADENCE_APP_PORT`, `CADENCE_APP_HOST` and
`CADENCE_APP_CONTRACT`.

## Use it in an app repository

Copy the template, then change the identity in both `package.json`
(`cadence.app`) and `app/app.md` (`app:`). The build reads the id from
`app/app.md` and writes `app/screens/main/screens.json`.

The build finds the app-kit in this order:

1. `CADENCE_APP_KIT` (direct `bun scripts/build.mjs` only);
2. `app-kit/` inside the app (vendor it);
3. `../app-kit` (the archive sibling layout);
4. `../../ui/app-kit` (the Cadence checkout).

`cadence app dev` runs the check in a scrubbed environment, so
`CADENCE_APP_KIT` is not available there. For that loop, vendor the app-kit
at `app-kit/` or keep the template and `app-kit/` siblings. In the archive,
copy both out together.

## Checks and install

```sh
sh scripts/pre-push
cadence app catalog install-check ./app
cadence app catalog install ./app --expected-digest 'sha256:…'
```

The `app` directory is the installable bundle; `app/screens/main/` is
generated by `bun scripts/build.mjs` and must be rebuilt before install.
Use the digest returned by `install-check`; never install unpinned.

## What to replace

- `app/app.md`: identity, title, summary, capabilities and workflow.
- `src/main.js`: the surface projection and app-owned actions.
- `src/styles.css`: layout using the host's design tokens.
- `app/workflows/hello.md`: the real workflow.

Read the [Cadence app development guide](https://github.com/favcrm/cadence/blob/main/docs/guides/app-development.md) for the full local/hosted path.
