One boundary, before the workspace.

Accepted design reference. No real authentication, API calls, email delivery or publishing actions. The sign-in handoff is simulated, not a replacement for AgenticOS sign-in.

Design owners reused

  • Unchanged cadence/design/tokens.css and kit.css: themes, type, buttons and controls.
  • Compact board reference: design-plans/clean-board-mockup. This proposal retains the current token palette rather than adopting its experimental light palette.
  • AgenticOS AuthProvider / App: checking, signed-out, error and authenticated branches.
  • Cadence SignIn / Login: session status and handoff; Sidebar / AccountMenu: authenticated shell. HTML approximations, not imported React components.

Accepted implementation contract

Bootstrap private surfaces before mounting workspace reads, polls or streams. On confirmed logout, expiry or identity change, unmount private content and clear prior-session caches. Unknown is not signed-out. Never use operator privileges as the basic sign-in gate. Keep existing valid authentication across navigation and same-tab reload without extending server expiry.

Try the transitions

Play the sign-in flow. In the workspace, type a private draft and choose Recheck session: the draft returns only after same-session verification. Simulate expiry: the workspace disappears and the draft is discarded. Explicit read-only mode is a separate browsing policy, not an authentication fallback.
