Plan on a page · 2026-09-23

Your AI dev team, on your machine.

Cadence turns the coding agents you already pay for into one team: a master agent you chat with plans the work, workers deliver it, an independent reviewer verifies it, and you approve what matters. Local-first, provider-neutral, and it remembers everything.

AFive product pillars

1 · One-command start

curl | sh or a paste-in agent prompt → cadence setup → browser wizard. Linux + macOS.

2 · A master that remembers

Chat with Claude, Codex or Pi. Conversations live in Cadence, not the provider session; restore, import and backups mean nobody starts empty.

3 · Plans you approve, work that is verified

Plan cards, daemon-enforced dispatch gate, independent reviewer, verdicts pinned to the exact commit.

4 · Any agent

Claude, Codex, Pi, Cursor, Devin as workers — the subscriptions you already have. No lock-in.

5 · Ship through platforms

Generic platform contract; every send, publish, deploy or spend is an effect card you press. AgenticOS v2 and Cloudflare first.

Product direction & go-to-market · 2026-09-23

Don't sell parallel agents. Sell work you can trust.

Running several agents at once is now built into Claude Code, Codex, Cursor, Copilot and a dozen free apps. What nobody neutral offers is a governed team: a plan you approve, workers from any vendor, a different vendor reviewing, verdicts pinned to the exact commit, and nothing shipped without your press. Local, open source, and it remembers.

01Market, September 2026

Verified against primary sources on 2026-09-23 (footer). Revenue figures for private companies are deliberately left out.

Vendors bundled the master

Claude Code Projects: "Claude scopes the request, delegates the work, coordinates parallel threads, reviews the outputs" — public beta on Pro/Max, threads in the cloud today, local "coming very soon" (Sep 17). Codex app, Cursor 3 and GitHub Agent HQ ship multi-agent too.

The local quadrant is crowded but shallow

Conductor, Superset, Claude Squad, Nimbalyst, Vibe Kanban: session runners with worktrees and a diff view. None has plans, independent review, approval gates or continuity.

Free tools die, open local tools survive

Terragon shut down Feb 9 and bloop (Vibe Kanban's company) on Apr 10, 2026; Vibe Kanban lives on "open source and community maintained" because it was local.

Trust is the bottleneck

Stack Overflow 2025: only 3.1% of developers highly trust AI output; 46% distrust vs 33% trust. Governance, not throughput, is the unmet need — the lesson Cadence learned dogfooding: review, not worker count, is the bottleneck.

Proposal v2 · 2026-09-23 · status: for review

From curl | sh to a master agent that remembers, plans, delegates and ships — with you approving what matters.

A developer installs Cadence with one command (or by pasting a prompt into their coding agent). The daemon starts a local web UI. Setup checks the machine, restores or imports existing work so nobody starts empty, and launches a master agent (Claude, Codex or Pi). The master keeps a durable conversation that survives restarts and lost provider sessions; it creates projects, proposes plans, and — after one approval — delegates to workers and brings merges, sends and deploys back as decisions. Connected platforms add managed services; AgenticOS v2 is the reference platform.

01Where we are

Cadence at origin/main 9ae2e52 (this checkout's main is 28 behind) and AgenticOS v2 at staging c330262.

Strong foundation

Durable messages & jobs, 4 provider adapters, git-native tracker, SHA-pinned verdicts, monitor alerts, secret scan, approval broker for headless Claude, tmux socket per state dir.

No front door

No release workflow, install script, init/setup. Release dirs are a host convention.

UI is a read-mostly board

Issue writes only; no launch / send / dispatch / project-create endpoints, and BOARD.md forbids them without auth.

Users start empty

Lost provider session → blank new session, no replay. Claude intermediate text never stored. No export/backup (rollout backup is a receipt only). Only ~/pm is portable.

Identity gap

Non-agent callers are "the operator" (CAD-280); same-UID socket trust; macOS lacks /proc attribution.

AgenticOS v2 is early

Email-OTP cookies only, no tokens/OAuth; no approvals (send = owner presses "Post now"); connectors on branches; gateway ledger merged, public billing not. AOS-34 chose Cadence as its agent runtime.

Tension to respect: the 09-22 audit recommends freezing L4 autonomy until the unattended acceptance harness (CAD-225) is green — 7 steps UNSUPPORTED. This plan ships chat, continuity, planning and approved delegation first; auto-merge waits for CAD-225.

05Install & setup

One command

curl -fsSL https://raw.githubusercontent.com/favcrm/cadence/main/install.sh | sh — OS/arch detect, tarball + .sha256, ~/.local/share/cadence/releases/<ver>/, link ~/.local/bin/cadence, then cadence setup. --prefix for sandboxes.

Or an agent prompt

docs/INSTALL-AGENT.md: paste into Claude Code / Codex / Cursor. Runs installer and cadence setup --json --no-open; reports URL and each failed check with its fix.

cadence setup

Idempotent: state dir → tracker → skill → daemon → UI → operator login link. Detects an existing install and never re-initialises over it.

Start options (wizard step 1)

Start fresh · Restore a backup (bundle file) · Connect my tracker (git URL) · Import local repos and GitHub issues. Repo paths are remapped by remote URL.

Release & upgrade

Tag v* → linux x86_64/aarch64 + macOS arm64 with UI embedded, checksums. cadence self-update takes an automatic backup, swaps the link, daemon restart --when-idle.

Thread ≠ provider session

The master's conversation is a Cadence thread. A provider session is disposable: when it is lost, compacted or the provider changes, a new session starts with the continuity pack (summary + last N turns + plan state + preferences) instead of blank.

Summaries without extra spend

The master writes a checkpoint summary at plan approval and every ~40 turns as part of its own turn; Cadence stores it. No hidden model calls.

Backup that is a backup

cadence backup uses SQLite online backup + manifest (schema, sha256, versions); nightly by default, keep 7. Replaces receipt-only rollout backups and gates self-update.

Export / restore

cadence export --bundle → one file: store snapshot, tracker remote, repo map, briefings. Credentials excluded, secret-scanned. cadence restore or wizard "Restore a backup".

Retention

Roll up delivery-noise events (30k of 50k live rows are submitting); archive threads, never silently delete; agent rm keeps thread history unless asked.

Platform sync (optional)

Encrypted bundle to the platform's files API (AgenticOS v2 files merged, AOS-41) and a status projection of plans/threads — the platform never becomes the authority (AOS-34 rule).

Adapters emit payload events (assistant_text, tool_call, tool_result, turn_result) written to the thread. Claude adapter extended; Codex already persists messages; Pi adapter via --mode rpc. /api/threads/:id, /messages, /stream, /interrupt.

Tools = cadence CLI

New verbs: cadence project new, cadence plan propose --file plan.yaml, cadence thread summary. Platform tools arrive through the proxy as MCP.

09Connected platforms — AgenticOS v2 as reference

Cadence integrates with a platform contract, not a vendor. AgenticOS v2 is the first implementation; a user's own Cloudflare account is the second.

1 · Connect

Credential exchange started by the operator: device-style code, platform sign-in, scope consent, revocable credential returned to Cadence. No cookies copied.

2 · Tools

MCP tools (local proxy first, remote Streamable HTTP later). Every tool declares an effect: read, draft, send (message, publish, deploy, spend).

3 · Effect gate

read/draft run within scope. send returns a pending effect; the operator presses it in Cadence (and the platform may ask again). Agents never execute sends.

4 · Usage & files

Optional: model access (gateway), usage/credits read-out, file storage for encrypted backups, status projection.
